Featured project
DocIntel — an enterprise-style agentic RAG system, built the way production systems actually need to work, not the way demos usually do:

A LangGraph agent that plans before it retrieves — a planner node decides per-turn whether a message needs a fresh document search or can be answered from conversation memory, instead of running retrieval on every message.
NeMo Guardrails screens every request before it reaches the agent, blocking jailbreaks and off-topic input.
Qdrant vector search reranked with a FlashRank cross-encoder, instead of trusting raw top-k hits.
Every LLM call routes through a Portkey gateway (retry, response cache, provider fallback) rather than a bare SDK client.
Full request tracing with Pydantic Logfire — guardrail verdicts, planner decisions, retrieval hits, and cache status, all inspectable.
